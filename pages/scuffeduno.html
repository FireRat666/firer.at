How to set room code:

1. Click Create Room above.
2. In the room lobby, click the edit icon next to the room code, type your custom code (e.g. bant or fire), and click Change Room Code.
3. Friends can then click the matching preset room button or enter the code above to join directly.

What is ScuffedUNO?

ScuffedUNO (scuffeduno.online) is a multiplayer UNO-style card game that runs in your web browser.
It also works on the in-game browser screens in AltspaceVR (altvr.app) and BanterVR, which makes it a popular pick for VR game nights.
This page just saves you typing: the buttons open the matching ScuffedUNO room directly.

Fire-V-Player

A video player for your Altspace world that everyone watches together, in sync. Play YouTube, Twitch, Vimeo, Tubi, NASA+, public-domain films, streams and video files. Build a shared playlist, vote on what plays next, or switch to karaoke mode with a singer queue. Adding it takes a few minutes and no coding.

2a. Add it in Unity

You need a Unity project with the Altspace / Banter Creator SDK already set up, and your world's scene open.

  1. Make an empty object. In the top menu choose GameObject › Create Empty. Rename it to Fire-V-Player so you can find it later (the name of the object doesn't matter, only the slug does).
  2. Put it at the middle of the world. With the new object selected, look at Transform in the Inspector and set Position to 0 0 0 and Rotation to 0 0 0. Why: you don't move the player by moving this object. You move it with the snippet's own settings (step 6). If the object (or anything it's inside) isn't at 0 0 0, the SDK's blue boxes won't line up with where the screen really appears. The orange preview always shows the real spot, and puts a yellow note on the object when it's been moved.
  3. Add the Snippet component. Click Add Component, type Snippet in the search box, and pick BS › Snippet.
  4. Type the slug and press Enter. In the Snippet's Slug box type and press Enter (the box only takes it after Enter or clicking somewhere else). It downloads the player and adds it to your world's Assets/WebRoot/index.html for you. After a moment the Inspector shows the title Fire-V-Player and a list of settings. If nothing happens, click Refresh from server.
  5. Save the scene. Press Ctrl + S (Windows / Linux) or Cmd + S (Mac). Do this every time you add or remove a snippet. Closing Unity without saving is the main way extra copies of the snippet end up in index.html.
  6. Place the screen. Change the settings in the Inspector, or drag the handles in the Scene view to move the screen, the buttons and the playlist panel. See Settings for what each one does.
  7. (Strongly recommended) Install the preview script so you can see the real size and angle of everything while you place it. It takes one minute: Preview script steps.
  8. Upload your world the same way you always do, then join it and press Playlist under the screen.

Without the preview script you only see the SDK's plain blue boxes. They show where things go but not their real size or angle. That's normal, not a bug. The preview script adds the orange outlines that match what you'll see in the world.

2b. Add it on the website

  1. Open your world for editing on altvr.app and go to the Snippets section.
  2. Find Fire-V-Player. Set the list to show All snippets, then search for Fire-V-Player (or scroll to it) and open it.
  3. Copy it. Click Copy & open index.html. This copies the snippet's code and opens your world's HTML.
  4. Paste it in the right place. If your HTML has these two lines, paste between them: 
    <!-- snippet section -->
   paste here
<!-- end snippet section -->
    If it doesn't have them, paste it just before </body>. Paste it once: check there isn't already a <bs-snippet name="fire-v-player" in there.
  5. Change the settings by editing the values in quotes in the pasted code, for example volume="10" to volume="30". See Settings.
  6. Save, then join your world and press Playlist under the screen.

Keep the code tidy. Every value needs quotes around it (volume="30", not volume=30), and a & in a link must be written as &amp;. Unity reads this part strictly, and one mistake can break the whole snippet section.

2c. Banter: add it with a script tag

In a Banter world, add the player with one <script> tag in your world's HTML. The file you load picks the mode:

  • Playlist mode (a shared playlist everyone adds to): https://vidya.firer.at/playlist.js
  • Karaoke mode (people queue up and take turns singing): https://vidya.firer.at/karaoke.js

Playlist mode

<script
  src="https://vidya.firer.at/playlist.js"
  instance="my-private-room"
  playlist="PLZWiw-xxQ4SPDmADhvme7-pU2bx3s7nKX"
  volume="10"
  hand-controls="true"
  position="0 1.5 -2"
  rotation="0 0 0"
  scale="2 2 2"
></script>

Karaoke mode

<script
  src="https://vidya.firer.at/karaoke.js"
  instance="my-karaoke-bar"
  volume="10"
  hand-controls="true"
  position="0 1.5 -2"
  rotation="0 0 0"
  scale="2 2 2"
></script>

Every setting from Every setting works here as an attribute on the tag.

Script tags and snippets count differently.

  • Room: a script tag names its room with instance, a snippet with room.
  • Position and rotation: script tags use A-Frame axes, where Z is flipped from Unity's. Script position="0 1.5 -2" is snippet position="0 1.5 2".
  • Scale: a script tag takes x y z, a snippet a single number.

The player builds everything with the BS SDK, so the page needs no <a-scene>. One left over from older versions does no harm.

3. The Unity preview script (optional, Unity only)

A small helper file for the Unity editor. While the Fire-V-Player object is selected, it draws exactly where the player will put things, at their real size and angle, and updates the moment you change a setting:

  • Orange: the screen, the row of buttons and the playlist panel.
  • Pink: the Singers button (karaoke mode only), with its own drag handle.

It only runs inside the Unity editor. It never goes into your uploaded world and does nothing for visitors.

Download FireVPlayerSnippetPreview.cs View it on GitHub

Install it

  1. Download the file with the button above. It's called FireVPlayerSnippetPreview.cs. Windows: make sure it didn't get saved as FireVPlayerSnippetPreview.cs.txt. Windows hides the end of file names by default; in File Explorer turn on View › Show › File name extensions to check. If it ends in .txt, rename it to end in .cs.
  2. Make a folder called Editor. In Unity's Project window, right-click the Assets folder and choose Create › Folder. Name it exactly Editor: capital E, no spaces, nothing else. If you already have an Assets/Editor folder, just use that one.
  3. Drag the file into that Editor folder from your Downloads folder (File Explorer on Windows, Finder on Mac). It must end up at Assets/Editor/FireVPlayerSnippetPreview.cs. In any other folder Unity can't build it and shows red errors.
  4. Wait for Unity to finish loading (the spinner in the bottom-right corner stops).
  5. Click your Fire-V-Player object in the Hierarchy. The orange outlines appear in the Scene view.

Updating it? Replace the old file, don't add a second one. Two copies of this script anywhere in your project (even in different folders) stop Unity building any of your scripts. Search the Project window for FireVPlayerSnippetPreview to make sure there's only one.

4. Show the video on more screens (Unity)

You can show what the player is playing on any number of extra surfaces in your world: a second screen at the back of the room, a curved screen, even a sphere.

Second screens (the easy way)

  1. Pick or make an object to show the video on. Any shape works: a flat quad, a curved screen, a sphere. It needs no camera or render texture.
  2. Give it a BS Material component.
  3. Name the object Fire-V-Player, or anything that starts with it, such as Fire-V-Player Left Wall. Typing Fire-V-Player into the BS Material's Texture box also works, but some clients load that box empty, so the name is the safer choice.
  4. (Optional) Show a loading picture. Before the player starts, Unity draws a screen marked by its name as plain white. To show the "Fire-V-Player loading" picture from the moment the world loads, put this link in the BS Material's Texture:

In the world, a second screen shows whatever the player's own screen draws:

  • YouTube and most links: the video, as on the main screen.
  • Twitch: the player's own browser.
  • Video files on the world's video player: there's no picture to share, so second screens go black.

While the player loads, second screens show the loading picture. Second screens only work in the world, not in Unity's Play mode.

Ready-made second screens

The FireVPlayerSecondScreen.cs helper adds a menu that makes a second screen for you: a 16:9 quad named Fire-V-Player, as wide as the player's screen, with the loading picture already set.

Download FireVPlayerSecondScreen.cs View it on GitHub

  1. Put it in the same Editor folder as the preview script (Assets/Editor/). The preview script install steps work the same way for this file.
  2. Make a screen: choose GameObject › Fire-V-Player › Second Screen, or right-click in the Hierarchy.
  3. Move it wherever you want it.

Camera screens

A camera screen is a camera filming the player's screen into a render texture, such as a "RenderTextureScreen" prefab. Unlike second screens, it also shows video files. The cost is a second render of the scene every frame.

  • Fit it: the camera must film exactly the screen. Its orthographic size is half the screen's height: 0.28125 × the snippet's scale, so 0.5625 at scale="2". If it doesn't match, the picture comes out cropped or shrunk.
  • Set it up for you: with FireVPlayerSecondScreen.cs installed, select the prefab and choose GameObject › Fire-V-Player › Fit Camera Screen to Player. That moves the prefab to where the screen is and sizes its cameras.
  • Before you build: turn off any placeholder screen in the prefab. It sits where the video is and flickers with it.

How snippet settings work

  • position and rotation are Unity world values, as for every snippet, so the Scene view handle shows where the screen will be.
  • scale can be a single number. At scale 1 the screen is 1 m wide and 0.5625 m tall, whatever the resolution.
  • karaoke is a checkbox. Ticked (true) is karaoke mode. Unticked or empty is playlist mode. A hand-written mode="karaoke" works too. Both modes use the same settings. playlist only matters in playlist mode.
  • The room is room, not instance, because Unity's Snippet component writes its own instance. Without room, each space gets its own room.
  • button-position is where the row of buttons goes, as a world position with its own drag handle. Empty or 0 0 0 puts them just under the screen. An empty or 0 0 0 button-rotation uses the screen's rotation.
  • playlist-panel-position and playlist-panel-rotation place the panel in the world, and it has its own drag handle. Clear playlist-panel-position to put the panel beside the screen. playlist-panel-rotation is then relative to the screen.
  • singer-button-position and singer-button-rotation (karaoke) place the Singers button, as a world position and rotation.
    • 0 0 0 or empty means the default. The button goes below and in front of the row of buttons, tilted back 30° and turned with the screen.
    • The SDK gives it no drag handle. The preview script adds one while karaoke is on.
    • They default to 0 0 0 rather than empty so Unity shows X, Y and Z boxes instead of one text box.
  • controls-follow-screen="true" makes the button, panel and Singers button positions and rotations offsets from the screen, in the screen's own axes. They then move and turn with the screen. For example, button-position="0 -0.67 0" puts the buttons 0.67 m below the screen's centre. Their drag handles then don't show where they really go.
  • An empty youtube uses the default silent video.
  • Unity reads the snippet section as XML. Quote every value, close every element, and write & as &amp;.

6. Using it in your world

The buttons under the screen

From left to right:

Playlist(Singers in karaoke) Skip backyour screen only Skip forwardyour screen only Muteyou only Volume downyou only Volume upyou only

The row also has Reload (just after Playlist; reloads your screen only, see below) and, for the host only, Play/Pause (just before the skip buttons). Turn them off with reload-button="false" and play-pause-button="false".

The playlist panel

Press Playlist to open the panel next to the screen. Its main view has:

  • Playback and volume controls, and Reload.
  • The playlist. Play, reorder, remove and vote on videos.
  • Lists: saved playlists (see Saved lists).
  • Search. Find a video, or paste a video link or a playlist link. A playlist link asks whether to replace the playlist, add it all, or save it to Lists.
    • Under the search box are your last five searches. Click one to search again. Clear forgets them. They're kept on your device only.
    • In karaoke mode, + karaoke, + lyrics and + zoom karaoke add that word to your search.
  • Refresh gets the latest playlist from the server. The panel also does this every time it opens.

Moving round a long playlist

  • The list scrolls with the thumbstick, or drag it. It shows 20 rows at a time and opens at the video that's playing.
  • Beside the tabs, 21-40 / 300 says which rows you're seeing.
  • < and > move 20 rows. << and >> move 100. |< and >| go to the start and end.
  • Now jumps back to the video that's playing.
  • On a client without scrolling lists, it shows pages of 7 and the same buttons turn the pages.

Moving the panel

  • Carry it: in VR, grab the pill under the panel and carry it. It stays upright and stays where you let go. Only your own panel moves.
  • Hand Playlist button: opens the panel in front of you.
  • Karaoke Singers button: opens it just above that button.
  • Playlist button by the screen: puts it back beside the screen.

More...

More... opens a second view with:

  • Host controls: Lock, Take Over, Voting, Clear, load the default playlist, and seek to a time.
  • Your player only:
    • Reload Video, and skip back and forward.
    • Auto Sync.
    • Captions: on or off for you, remembered on your device.
    • Resolution: steps your screen through 1280×720, 1600×900 and 1920×1080, then back to the snippet's setting. Remembered on your device.
    • Hand Controls, when the snippet has them (see below).
  • Add by link: a video (YouTube, Twitch, Vimeo or any link from What it can play), or a YouTube playlist or list of links. Add adds a video, and asks what to do with a playlist.
  • Space admins only: Admin Take Over and the playlist / karaoke switch (see Space admins).

When someone can't play a video, the panel shows a suggested replacement with Replace (host) and Dismiss.

Hand controls

With hand-controls="true", everyone gets seven buttons that go with them: mute, volume down, volume up, reload, skip back, skip forward and the Playlist (or Singers) panel. More... › Hand Controls moves them, one place per click, and your choice is remembered on your device:

  • Left Wrist: on the back of the left wrist. The default in VR.
  • Right Wrist: the same on the right wrist, for when another menu is on your left hand.
  • In View: at the bottom right of what you see, wherever you look. The default on desktop, where you can't turn your hand to see the buttons.
  • In Front: left in the world just in front of you, facing you. Choose it again later to bring them to where you are now.
  • Off: no hand buttons.

hand-controls-place sets where they start for people who haven't chosen. The buttons come back if you leave and rejoin the space.

Reloading your screen

When a video or stream freezes or won't load for you, press Reload to rebuild your own screen. It's the circular arrow under the screen and on the hand controls, the panel's Reload, or More... › Reload Video. The video starts again at the same point as everyone else's, as when someone joins late. Nobody else's screen changes, so the host doesn't need to switch videos back and forth to fix it for you. In karaoke it's in More... and on the hand controls.

Saved lists

The panel's Lists tab shows the snippet's playlists: the default playlist first, then each one in playlists. playlists is a comma-separated list of YouTube playlists and playlists of links, up to 10 in all:

playlists="PLZWiw-xxQ4SPDmADhvme7-pU2bx3s7nKX, https://docs.google.com/document/d/<id>/edit, https://example.com/friday.m3u"

Which YouTube playlists work:

  • How to give one: its ID, or any link with list= in it, including a video in a playlist.
  • Works: playlists (PL...), albums (OLAK5uy_...) and a channel's uploads (UU...).
  • Doesn't work: mixes (RD...), as they have no fixed list.

playlists can also hold single videos and streams, each shown as a list of one. That's handy for a YouTube live stream or a VRCDN stream:

playlists="PLZWiw-xxQ4SPDmADhvme7-pU2bx3s7nKX, https://www.youtube.com/watch?v=jfKfPfyJRdk, https://stream.vrcdn.live/live/vrcdn.live.ts"

Each list shows its name and how many videos it has.

  • Open lists its videos, each with Add. The host also gets Play Now and Play Next, or Play when the video is already in the playlist.
  • Add All adds every video to the end of the playlist, skipping ones already in it.
  • Replace (host) makes the list the playlist.

Adding follows the usual rules: anyone can add while the player is unlocked, and only the host while it's locked.

You can also save lists from inside the world. Pasting a YouTube playlist or a list of links into Search or Add by link asks what to do with it:

  • Replace Playlist (host).
  • Add All to End.
  • Save for Everyone adds it to the room's shared lists, marked (shared) with who saved it.
    • The server checks the list works first.
    • It's kept with the playlist, so it's still there next time, and everyone in the room sees it straight away.
    • Saving and Remove follow the same rules as adding. A room keeps up to 50.
  • Save for Me keeps it on your device only, for this world, marked (mine). Share turns it into a shared list, and Remove takes it out.
  • Just This Video, for a video link that's part of a playlist.

The snippet's lists come first, then the shared ones, then your own. The server remembers what it read from a list for 5 minutes, so a change to the file shows after that.

Who's in charge (the host)

  • The host controls what plays for everyone. If you can't skip or change the video, someone else is the host.
  • To become the host, open More... and press Take Over. The host can Lock the player so nobody else can take over, and can turn on Voting so people vote on what plays next.

Karaoke mode

Whoever runs the karaoke should press Take Over first, as only the host can start other people's songs. The Singers button (and Join/Leave Queue) opens the panel as a Singers panel:

  • Now singing shows who is singing which song. The host and the singer get Restart Song and Stop Song.
  • Singers is the queue.
    • The host can Play & Sing anyone, move singers Up or Down, and Remove them.
    • The singer at the top can start their own song.
    • Anyone can Remove Me.
  • Search finds a song, or takes a pasted video link. Sing It puts you in the queue with that song. You can be in the queue once.
  • More... has the host controls, including Auto Advance, which starts the next singer when a song ends. It also has seek, and your own skip, Auto Sync and Captions.

Singing area (optional). The box-trigger-* settings add a box people stand in to sing:

  • With box-trigger-enter-enabled, the next singer's song starts when they walk in.
  • With box-trigger-exit-enabled, the song stops and they leave the queue 5 seconds after they've completely left the box.

See Every setting.

World owners and moderators can switch between playlist and karaoke without uploading the world again. See Space admins.

7. What it can play

Search, and Add by link, take far more than YouTube. Paste a link and it shows as a single result to add or play.

Search sources

The button beside the search box picks what to search:

  • YouTube.
  • Archive Films: the Internet Archive's public-domain films and TV.
  • Tubi. Tubi has no public search, so this looks through the titles in Tubi's categories (a couple of thousand).
    • The first Tubi search after the server starts takes several seconds. Later ones are instant for six hours.
    • A series in the results adds its first episode. Paste the series link to see every episode.
  • NASA+.

Always allowed

These sites moderate what's on them, so they always work:

Library of Congress films

These links all work, in search, Load Playlist and list files:

  • The film's page: https://www.loc.gov/item/<id>/, or https://lccn.loc.gov/<id>.
  • Its permanent link: http://hdl.loc.gov/loc.mbrsmi/<collection>.<number>, or https://www.loc.gov/resource/mbrsmi.<collection>.<number>/.
  • The MP4 file itself, from the page's Download menu.

Pages whose ID starts with mbrs (most of them) always work. For other pages the server has to ask loc.gov, which often turns servers away. If it says it can't find the film, paste its permanent link or MP4 link instead.

The public-domain National Film Registry films are built in. Their free-to-use page works as a list of 15 films. Three of its 18 early films have no known video file yet. The films are big (hundreds of MB to a few GB, at 1080p), but they stream, so they start as quickly as any video.

Links from any site (needs untrusted-links="true")

These can come from anywhere and aren't moderated. They only work when the snippet has untrusted-links="true". Without it, the server won't add them, and a player whose world doesn't allow them shows a notice instead.

If a browser won't start a file with sound, it starts muted and the sound comes on at the first click on the screen.

How video files play

Many file hosts won't let a web page on another site load their files, so in a world a video file plays on the SDK's own video player (Unity's) instead of in the browser.

  • One at a time: while a file plays, the browser screen is swapped for the video player, and it swaps back when the playlist moves on.
  • Controls: volume, mute, spatial, skips, pause and the host's controls work as usual.
  • Sync: Unity's player can't change speed, so it jumps when it's more than a second out of step.
  • Formats: MP4 with H.264 video is safest, especially on Quest. On PC, WebM needs VP8 video, not VP9. Ogg Theora video doesn't play on Quest at all.
  • Audio files play in the browser screen, so their host must let other sites play its files.
  • Size: the video player is sized like the browser screen. Set native-screen-size if it doesn't match yours.
  • Outside a world (the 2D page), files still play in the browser.

Good to know

  • Length: files, streams and Twitch videos show no length until the first player loads them. After that the playlist moves on when they end.
    • A file whose length can't be found still plays, syncs, pauses and seeks.
    • It stays on its last frame until someone skips.
  • Captions work for YouTube, Vimeo, and HLS and DASH streams that have them (English when there's a choice).
  • Region check: "unavailable in your region" only applies to YouTube.
  • Not supported: pages that need a login, and Dailymotion, whose player now needs a Dailymotion account.

Playlists of links

playlist, playlists and Load Playlist also take a link to a list of videos from anywhere:

  • A text file of links, one per line. It can be a .txt or .m3u file at a direct link, on Dropbox or on Google Drive, or a Google Doc. Give the share link, and share it so anyone with the link can see it.
  • A Google Drive folder shared with anyone who has the link: every video directly inside it, sorted by name. Subfolders are skipped.
  • An archive.org item (https://archive.org/details/<id>): its videos.
  • A Library of Congress free-to-use page: its films.

A list file can mix everything the player plays: YouTube videos and playlists (each playlist is expanded), Twitch, Vimeo, VDO.Ninja, streams, files, Drive and Dropbox files, archive.org items and Library of Congress films.

  • Blank lines and lines starting with # are ignored.
  • Text after a link on the same line becomes that video's title. So does an m3u #EXTINF:<seconds>,<title> line above it.
  • #PLAYLIST:<name> names the list. Without it, the list is named after the file.
#PLAYLIST:Friday night
https://youtu.be/aqz-KE-bpKQ
https://www.youtube.com/playlist?list=PLZWiw-xxQ4SPDmADhvme7-pU2bx3s7nKX
https://www.dropbox.com/scl/fi/<id>/opening.mp4?rlkey=<key>&dl=0 Opening night
#EXTINF:0,Q&A
https://drive.google.com/file/d/<id>/view
https://www.twitch.tv/<channel>
https://archive.org/details/Popeye_forPresident

Example list: example-playlist.txt has a bit of everything, so it doubles as a test of what plays where. It includes:

  • a YouTube live stream, a Twitch channel and a VRCDN stream
  • HLS and DASH streams
  • video files in many formats
  • audio files
  • a Library of Congress film

Limits:

  • Size: at most 300 videos (500 for a YouTube playlist), from at most 300 lines, in a file of up to 256 KB.
  • Skipped lines: lines that can't be played are skipped, and the panel says how many. So are links from any site when untrusted-links is off.
  • First load: a list with many YouTube links takes a while to load the first time, as each one is looked up.
  • Refused: links to the server's own network (localhost, private addresses).

8. Space admin tools

At the bottom of the panel's More... view, the Space admins only section has tools for the world's owner, an Owner or Moderator of the community hosting it, or a SideQuest admin.

Everyone sees these buttons, because the client can't always tell who is a space admin, but they only work for space admins. When someone else presses one, nothing changes and the panel says so after a few seconds.

Switching between playlist and karaoke

  • Switch to Karaoke / Switch to Playlist switches the player for everyone in the space, straight away. People who join later start in the saved mode.
  • Use Snippet Default appears once the mode has been changed, and goes back to the snippet's karaoke setting.
  • It lasts a day: the choice is saved as protected space state (the key fire-v-player-mode), which only space admins can write. Space state lasts 24 hours after its last change, so after a day with no changes the player goes back to the snippet's mode.
  • The playlist is kept while the room is in karaoke. Switching back brings it back and plays its current track from the start. Switching to karaoke stops what's playing.
  • The 2D page has no switch. Players using the 2D playlist page (playlist-ui="page") still follow the saved mode.

Admin Take Over

Admin Take Over (shown when you aren't the host) makes a space admin the host, even when the player is locked or the host has turned Take Over off. A world's owner or moderators can always stop someone running the player.

  • While the admin is in the space, nobody else can take over. They can turn it back on, or Lock and Unlock, like any host.
  • When they leave, the usual rule applies: 42 seconds later anyone can take over again, so people can still use the player when no admin is around.
  • It saves the admin's ID as protected space state (the key fire-v-player-admin).
  • The player server trusts the admin's player, as it trusts every player's own user ID. That stops anyone using the normal client, but not a modified one.
  • The room is shared by everyone with the same room, so an admin of one world can take control of a room another world uses too. Without a room, each space has its own.

Blacklist

The owner of the player server can stop someone using the player in every world.

  • What they see: the video plays and they hear it, at 100% volume.
  • What stops working: every button, the panel, the hand controls and clicking on the screen.
  • They aren't told why: the player just looks frozen to them.
  • Matched by user ID: it's their Banter user ID, not their name, so someone else with the same name isn't affected.

10. For developers

Once the player has started, your own page scripts can control the volume through window.videoPlayerCore:

// Set the volume to 50%

// Turn it up by 10%, or down by 15%

window.videoPlayerCore.setVolumeIncrement(-15);

Help, it's not working

Click a problem to see the fix.

I only see blue boxes in Unity, not the orange preview
  • Blue boxes are normal on their own: they come from the SDK. The orange preview only appears once the preview script is installed.
  • Check the file is at exactly Assets/Editor/FireVPlayerSnippetPreview.cs: folder named Editor, file ending in .cs (not .cs.txt).
  • Click the Fire-V-Player object in the Hierarchy: the preview only shows while it's selected.
  • Make sure the Scene view's Gizmos button (top right of the Scene view) is turned on.
  • Open Window › General › Console. Any red errors there stop the preview; see the next two problems.
  • Got an old copy? Download it again; older versions only worked if the slug was typed in lowercase.
Red errors in the Console mentioning "BS.SDKEditor", "UnityEditor" or "Handles"

The preview script is in the wrong folder. Move it into a folder named exactly Editor (for example Assets/Editor/). If it's already there, make sure the Creator SDK is installed in this project.

Red error: "already contains a definition for FireVPlayerSnippetPreview"

You have two copies of the preview script. Search the Project window for FireVPlayerSnippetPreview and delete every copy except the one in Assets/Editor.

The snippet shows up several times in index.html

Each copy comes from a Snippet component the SDK lost track of, usually after closing Unity without saving, or after adding the snippet again because it looked like it hadn't worked. Only the first copy is used, but the extras are confusing. To clean up:

  1. Make sure your scene has only one object with the Fire-V-Player Snippet. Delete any extra ones.
  2. In the top menu open Creator SDK › Setup › Tools, then Recover orphaned snippets and press Remove for the leftovers. (This tool needs Creator SDK 4.0.24 or newer. Older SDK: click Open index.html on the Snippet and delete the extra <bs-snippet name="fire-v-player" ... </bs-snippet> blocks by hand.)
  3. Save the scene (Ctrl/Cmd + S).

With the preview script installed, Unity's Console warns you when there's more than one copy, and the unused one is labelled NOT USED.

The Snippet shows no settings after I typed the slug
  • Press Enter after typing, or click Refresh from server.
  • Check the spelling: fire-v-player, with two dashes and no spaces.
  • Check you're online: the settings are downloaded.
There's no screen when I join my world
  • Did you upload the world again after adding the snippet?
  • Look where position says the screen is: it might be behind you, under the floor or inside a wall. Try 0 1.5 2 to put it near the middle of the world.
  • If you edited the code by hand, check every value has quotes around it.
I can't skip, pause or change the video

Someone else is the host. Open Playlist › More... and press Take Over. If it says the player is locked, the host has to unlock it first.

A video won't play

Some YouTube videos block being played on other sites, or aren't available in some countries. The panel suggests a replacement when it can; otherwise pick a different upload of the same video.

Still stuck? Get in touch or open an issue on GitHub. If it's a Unity problem, include a screenshot of the Snippet's Inspector and any red errors from the Console.
